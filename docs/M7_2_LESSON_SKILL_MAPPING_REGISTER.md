## 2. Review instructions

For each mapping, compare the skill definition in `content/curriculum/skill-catalog.json` against:
1. the lesson focus;
2. the learning objectives and teaching material;
3. the checkpoint / expected learner demonstration;
4. the place of the lesson in the curriculum sequence.

Record a decision for every lesson:
- **Keep** — every listed skill is directly taught, practised, or assessed.
- **Remove mapping** — a listed skill is incidental or unsupported by lesson content.
- **Add mapping** — an important assessable outcome is not represented by an existing skill ID.
- **Clarify** — the skill is relevant but the definition or lesson objective is too broad/ambiguous.
- **Escalate** — requires curriculum-owner judgement.

Do not add or remove IDs based on title similarity alone. A lesson can legitimately develop multiple skills, but each mapping needs evidence. Do not create new identifiers during this review unless a genuine capability gap is documented and approved.
