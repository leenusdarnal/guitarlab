# Security Policy

GuitarLab is a public source repository. Do not report vulnerabilities by opening a public issue with exploit details.

For a sensitive report, use GitHub's private vulnerability reporting feature if enabled for this repository, or contact the repository owner privately through GitHub. See [Security Response Policy](docs/SECURITY_RESPONSE_POLICY.md) for the response and disclosure process.

Do not commit secrets, Cloudflare credentials, private learner records or recordings. Microphone capture and any remote audio storage must be opt-in and clearly disclosed.
